# Not a Mac Thene for Discord 

A Discord theme that looks like macOS.

---

## Preview
![Not a Mac Theme for Discord Preview](https://raw.githubusercontent.com/Dreachu/namtfd/refs/heads/main/media/Preview.png?raw=true)

## Features

* **Window Controls**: macOS window controls.
* **Macos inspired Sidebar**: looks like a Mac app.
* **Rounded Corners**: corners are round
* **Appearence Support**: Supports the Discord color themes.

---
## Installation

A Discord client mod is required.
### BetterDiscord
1.  Download the `namftd.theme.css` or the `namftd-right.theme.css` file from the [latest release](https://github.com/Dreachu/namtfd/releases/latest).
2.  Open Discord settings.
3.  Navigate to the `Themes` section in the BetterDiscord section.
4.  Click the `Open Themes Folder` button.
5.  Move the downloaded `namftd.theme.css` or `namftd-right.theme.css` file into the opened folder.
6.  Return to Discord and enable `namftd` from the theme list.
